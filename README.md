# Send Welcome Messages

Moodle local plugin `local_sendwelcomemsg`.

Sends a configurable welcome message to users on enrolment, via event observers and a scheduled delivery task.

## Requirements

- Moodle with version number `2022041900` or later.

## Installation

Copy the plugin folder to `local/sendwelcomemsg` in your Moodle root, then visit
**Site administration → Notifications** to complete the database upgrade.

```
<moodle>/local/sendwelcomemsg
```

## Version

Release `1.0`. See `version.php` for the exact version number.
